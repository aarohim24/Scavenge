# Feedback log

A manual research log for the first public feedback round. Not analytics — no tracking is
or will be added.

What counts as signal here: **a stranger cloned the repo and ran it against a URL of their
own.** Stars are not evidence of anything.

## Maintainer note — do not react yet

Do not implement individual feature requests as they arrive. One request is an anecdote.
**Three independent people asking for the same capability** is evidence worth acting on, and
even then only after checking it does not require semantic reasoning the engine has already
refused once.

Record, but do not build on first request:

- more fields
- authentication, cookies, sessions
- proxy support
- crawling or link-following
- a browser extension
- arbitrary user-supplied schemas
- scraper code generation
- cloud hosting or a hosted API
- LLM integration of any kind

The most valuable thing this round can produce is a **broken target**, not a feature list.
